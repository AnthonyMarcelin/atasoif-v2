# Design system · Direction Nuit

Source unique pour l’UI À ta soif ! (explorations Carnet / Cave supprimées).

## Fichiers

| Fichier | Rôle |
|---|---|
| `AtaSoif-Nuit.dc.html` | Design system (fondations, composants, animations) + maquettes mobile / tablette |
| `AtaSoif-Assets.dc.html` | Marque : lockups, icônes app, splash (source pour régénérer les assets) |
| `support.js` | Runtime Cloud Design (requis pour ouvrir les `.dc.html`) |
| `.thumbnail` | Aperçu pack |

Ouvrir `AtaSoif-Nuit.dc.html` dans un navigateur (avec `support.js` à côté).

## Préférences produit

- **Pas de cadratin (—)** dans les textes ni les libellés. Utiliser `·`, `:`, une virgule ou deux phrases.
- Copy client en français, tutoiement, ton direct.
- App **mobile et tablette uniquement** (Angular + Capacitor iOS/Android). Aucune maquette desktop.
- Visuel : cave nocturne + rigueur de carnet. Bricolage Grotesque 800 / Schibsted Grotesk / Space Mono, zéro arrondi, zéro ombre, trait 1,5px, ambre `#E39A3C` en accent unique.
- Anti-slop : pas de dégradés décoratifs, pas d’emoji, pas de SVG dessinés à la main. Photos = placeholders rayés.
